# 2026 意大利旅行手册

一份可离线打开、也可直接发布到 GitHub Pages 的单文件旅行手册。

## 本地查看

直接用浏览器打开 `index.html`。页面没有外部依赖，不需要安装依赖、构建或启动开发服务器。

## 发布到 GitHub Pages

1. 将项目推送到 GitHub 仓库。
2. 打开仓库的 `Settings > Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 选择 `main` 分支和 `/ (root)` 目录后保存。

GitHub Pages 通常会在几分钟内生成公网地址。

## 数据边界

公开页面不包含姓名、证件号、票号、订单号、二维码或支付信息。旅行日期和住宿地点仍属于个人行程信息，发布公开仓库前应再次确认。

- 泰国航空行程截图中的四段航班时间
- 已确认的行程规划与预订状态
